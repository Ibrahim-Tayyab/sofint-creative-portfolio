# Sofint Solutions — Creative Portfolio Showcase

A bespoke, high-performance creative design showcase and digital portfolio developed for **Sofint Solutions** / **Sofint Digital Agency**.

---

## 🎨 Overview & Showcase Categories

- **Logo Designs & Brand Marks**: 66 bespoke brand concepts with full commercial rights and vector master handoffs.
- **Marketing & Print Media**: 96 high-impact brochures, business stationery, flyers, and publication layouts.
- **Product Packaging & Box Labels**: 54 production-ready 300 DPI CMYK dielines and photorealistic 3D mockup previews.
- **Apparel & Custom T-Shirt Graphics**: 30 screen-print ready vector apparel illustrations.

---

## ⚡ Features & Capabilities

- **Ultra-Fast Vanilla Architecture**: Pure HTML5, CSS3, and JavaScript — zero heavy runtime overhead, instant page loads.
- **Interactive Lightbox**: Full-resolution image previewer with keyboard navigation (`←`/`→`, `Esc`), swipe support, and one-click direct access to vector files.
- **Client Shortlist Drawer**: Allows prospective clients to heart/save concepts into a persistent shortlist drawer with 1-click clipboard export for proposals and chats (e.g. Freelancer.com, Upwork).
- **Direct Studio Inquiry Modal**: Built-in brief generator that pre-fills and connects directly to studio contact (`contact@sofintsolutions.tech`).
- **Fully Responsive & Accessible**: Fluid typography (`Outfit`, `Plus Jakarta Sans`), glassmorphism navigation, and dark/light contrast compliance.

## 🚀 Deployment (Vercel Ready)

This repository is pre-configured for one-click static deployment on **[Vercel](https://vercel.com/)**:

1. Import this repository in the Vercel dashboard.
2. Framework Preset: **Other / Static**.
3. Root Directory: `./` (default).
4. Click **Deploy**.

The included `vercel.json` automatically configures:
- Clean URLs (`/print-designs` serves `/print-designs.html`)
- Long-term caching for immutable media and assets (`public, max-age=31536000, immutable`)
- Modern HTTP security headers (`nosniff`, `SAMEORIGIN`, `strict-origin-when-cross-origin`)
- Seamless `404.html` fallback
